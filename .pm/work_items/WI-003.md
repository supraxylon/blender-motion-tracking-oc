# WI-003 - First Feature: Cached Pose Import

Status: ready for OpenCode.

Source:
- `README.md`
- `documentation/PLAN.md`
- `PROJECT_SUMMARY.md`

Goal: implement the first Blender-side feature: cached pose JSON -> Blender empties.

Why this first:
- It matches the v1 architecture.
- It avoids heavy ML dependency setup.
- It gives the MMPose worker a stable output target.

Branch tasks:
1. `WI-003-A` - JSON contract and validator.
2. `WI-003-B` - Blender add-on importer.
3. `WI-003-C` - smoke checks and usage docs.

Acceptance:
- Cached pose JSON has a clear schema.
- Sample JSON validates.
- Blender add-on can import the sample and create keyed empties.
- Validation can run without Blender where possible.
- Local Blender under `blender/` is used only for optional headless validation or source reference.
- No MMPose install.
- No armature retargeting.
