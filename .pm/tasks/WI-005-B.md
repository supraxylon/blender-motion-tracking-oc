# WI-005-B - Blender Runtime Probe

Objective: document exactly what works and fails for local Blender execution.

Deliverables:
- `tools/probe_blender_runtime.ps1`
- `.pm/reports/WI-005-B-blender-runtime-probe.md`

Requirements:
- Probe repo-local `blender.exe`.
- Probe repo-local bundled Python.
- Probe PATH commands: `python`, `blender`, `ffprobe`, `ffmpeg`.
- Do not install anything.
- Do not change system settings.
- Report exact command outcomes in plain language.

Acceptance:
- Probe script exists.
- Probe report exists.
- Report clearly states whether Blender launches.
- Report clearly states whether bundled Python can run validation scripts.

Out of scope:
- Fixing Blender.
- Installing runtimes.
- Editing Blender source.

Final report required:
- Files changed.
- Commands run.
- Validation result.
- Blockers.
