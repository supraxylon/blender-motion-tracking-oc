# WI-006-A - Backend Interface Cleanup

Objective: make worker backends easy to add without touching CLI logic every time.

Deliverables:
- `tracking_worker/backends/` package.
- Fixture backend moved or wrapped under that package.
- CLI still supports `--backend fixture`.

Acceptance:
- Existing worker command still passes.
- Existing worker tests still pass.
- Diffs stay small.

Out of scope:
- Real RTMPose implementation.
- Heavy dependency install.
- Blender code.
