# WI-006-B - RTMPose Missing-Dependency Adapter

Objective: add a safe `--backend rtmpose` path that explains missing dependencies.

Deliverables:
- RTMPose backend module.
- CLI recognizes `--backend rtmpose`.
- Clear error if torch/MMPose/OpenCV are unavailable.

Acceptance:
- `--backend fixture` still works.
- `--backend rtmpose` exits non-zero with a useful message when dependencies are missing.
- No dependency installation occurs.

Out of scope:
- Downloading models.
- Running real inference.
- GPU/CUDA setup.
