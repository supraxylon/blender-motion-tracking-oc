# Stand-Up Cadence

Purpose: keep work honest, short, and visible.

Every work session should update:

1. What changed since last stand-up.
2. What works.
3. What does not work.
4. Current blockers.
5. Next action.
6. Which agent owns which branch.

Keep each stand-up under one page.

Use `.pm/standups/YYYY-MM-DD.md`.

Do not hide failed validation. Failed checks are useful signal.
